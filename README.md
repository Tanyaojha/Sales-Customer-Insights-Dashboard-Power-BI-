# Sales-Customer-Insights-Dashboard-Power-BI-
"Interactive Power BI Sales Dashboard analyzing $100k+ in electronics revenue, featuring geographic mapping, product category performance, and customer segment analysis.


📊 Project Overview
This project features an interactive Power BI dashboard designed to analyze sales performance and customer demographics for a global electronics retailer. The goal of this dashboard is to provide actionable insights into revenue trends, product popularity, and regional market performance across the US, China, Germany, and India.

🚀 Key Features & Insights
Revenue Analysis: Tracked total sales of over $102,000 across 100 orders.

Product Performance: Identified Laptops as the top-performing category by revenue.

Geographic Breakdown: Visualized sales distribution across different countries, with the United States emerging as the primary market.

Customer Profiling: Analyzed customer scores and purchasing behavior to identify high-value segments.

Time-Series Trends: Visualized sales fluctuations from January 2024 to December 2026.

🛠️ Tools Used
Power BI Desktop: For data modeling, DAX calculations, and visualization.

Data Prep: Cleaned and transformed raw CSV data (Customer and Order tables).

DAX (Data Analysis Expressions): Used for creating custom measures such as Total Sales, Order Counts, and Category performance.
